# Security boundaries

This private companion repository contains no reader code, vendor binaries, private documents or deployment secrets. Runtime storage is outside tracked paths. Explicit staging and `scripts/audit_boundary.py --history` are required before publication; an ignore file alone is insufficient.

The API checks account/device ownership for every object. Device download access is a five-minute HMAC ticket plus the current revocable device bearer. Browser mutations require an exact allowed origin plus a per-session CSRF token. Sessions are server-side, 12 hours, HttpOnly/Secure/SameSite=Strict in production; passwords use salted scrypt. There is no public signup or browser-held provider token. Account bootstrap is an authorized interactive operator action.

Private file names are display metadata, never storage paths. Chunks are length/range checked, fsynced and only then recorded as received. No success is reported on storage failure. Finished uploads are checksum-verified then validated by a bounded separate process; content is never interpreted as a shell command. Workers have no credentials, no network code path, bounded archive expansion/XML structure/PDF object graph/image dimensions, resource limits and a 30-second process deadline. The production container adds a read-only source filesystem, private volume, dropped capabilities and no-new-privileges. This is process/container isolation, not a claim of a separately audited hostile-code sandbox.

Native documents with active scripts, actions, remote resources, encryption/DRM, unsafe ZIP/XML or unsupported constructs are rejected. DOCX conversion supports a documented subset and never runs office macros or fetches links. Parsing is not a proof against every future parser vulnerability: pin supported patched dependencies, run the advisory check, keep process limits, and independently validate on receipt before durable ACK. The initial bundled pypdf version was rejected by the dependency gate and upgraded to 6.18.1; no reported OSV advisories were found for the final pypdf/Pillow pins at the recorded check.

Tom has no tools, device control, file access or shell. It receives only explicitly consented frozen context, questions/handwriting and bounded supplied history. General mode rejects document context/page images; transcription also rejects document context. Untrusted source content is explicitly identified. API cost controls include model allowlisting, max input/images/output, daily request caps and concurrency limits. Cancel closes the provider response best-effort; it cannot undo incurred provider usage. Disconnects and restarts preserve partial output and never automatically retry billable operations.

Routine request logging is disabled. Public dependency checks send only package names/versions. Synthetic test credentials are temporary fixture data, never real credentials; generated runtime JSON is ignored and prohibited from the tracked repository.

Report discovered defects privately to the repository owner. Do not put document content, passwords, API keys, device credentials, handwritten notes or reader-specific evidence into issues or pull requests.
