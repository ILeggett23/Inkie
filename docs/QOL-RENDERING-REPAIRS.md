# Rendering and selection repairs

This change follows the installed source `cac87adca6a384d63aebb14b323a95193304993c`. The user reported incomplete Tom illustrations, lingering erased ink/highlights, old viewport artifacts during page turns, and incomplete Selection-tool block scope. The supplied photo shows pale yellow residual marks; a photograph alone does not distinguish stored content from optical ghosting.

## Software causes and changes

- **Erase masks:** the existing vendor converter footprint aligns by four pixels horizontally/two vertically and processes eight-pixel horizontal chunks. `ScopedEraseMask` previously replaced only the exact requested rectangle, leaving old mask bytes in the converter margin. It now saves the aligned footprint, zeros that margin, supplies the exact requested mask, and restores every saved byte. Requested update geometry and flags are unchanged. `qualityContent` uses the same footprint helper.
- **Semantic highlighting:** rendering joins glyphs into padded line blocks, while erasing previously hit-tested individual glyphs only. An eraser over a visibly highlighted space could therefore clear temporary pixels but retain the semantic highlight. Hit-testing now uses the same visible/clipped line blocks as rendering, transformed back into the eraser's source coordinates. Undo/redo and linked-record preservation remain in the existing transaction path.
- **Tom presentation:** cleanup was color-only and keyed by request ID. A monochrome visual or another viewport of the same request could lack a settled cleanup. Visible reply revisions now identify local cleanup for completed playback and scrolling; retiring a reply can clean immediately while the next provider job is still busy. Network/generation activity no longer declares already-composed UI pixels unsafe to present. Repeated `finishInstantly()` on an already finished viewport does no work. Tom exit explicitly retains retirement cleanup. All of these requests use the existing regional UI quality path and intact RGB.
- **Page ownership:** recursive page-ready processing can encounter an old styled-ink worker after the Reader's active binding has changed. Old results are no longer published to the new viewport. Composition checks the binding and uses the active prepared page without stale ink or transient overlays until its own ink is bound. Regional cleanup always recomposes current pixels, including page-turn cleanup.
- **Mixed responses:** reader and Companion previously rejected nonempty prose alongside a visual. Companion now advertises `X-Inkbound-Tom-Mixed-Reply: 1`; capable readers freeze `mixed_reply: true` in the reviewed request. Header propagation, helper IPC, runtime consent invalidation, frozen-wire reconstruction and configuration rechecks preserve this capability. Older clients retain the empty-prose visual contract. A mixed reply renders explanatory handwriting above the complete visual in one scrollable native group, preserving the streaming handwriting prefix and exact save geometry. Image/model/parent-request/source validation remains intact. History retains the actual prose separately from its visual summary.
- **Healthy Tom polling:** successful configuration/status requests no longer rewrite and fsync a network-state record that is already clean. An absent record already represents clean state. Failure/backoff/revocation and recovery transitions still persist, and credential checks still run before every request. The original receiver-overlap latency limit remains unchanged.
- **Selection:** at the user's explicit preference, Selection-tool drags expand to complete touched source paragraphs/blocks. Taps still select a word and existing handles still adjust exact edges. Source punctuation, line breaks, coordinates, IDs, capacity refusals and highlight anchors stay canonical.

## Refresh evidence boundary

The stock evidence establishes clipped regional quality and different live/settled update classes; it does not establish a universal ghosting threshold. These changes reuse the verified public UI mode and partial flags. No proprietary library, waveform constant, full-refresh suppression or new ghosting threshold is introduced. Software tests establish pixel/state correctness and request geometry; they cannot prove removal of physical pigment ghosts.

## Validation

Regressions cover unaligned mask margins/restoration, highlighted spaces with undo/redo, stale page binding, whole-block Selection, immutable mixed text/visual geometry, no-op final replay, viewport scrolling, capability negotiation, exact frozen-wire reconstruction and durable Worker streaming. Release, ASan/UBSan and ARM SDK checks run in GitHub; the retired VM remains retired. The Companion bundle is built for review without deploying the service. No tablet operation is part of this source-change verification.
