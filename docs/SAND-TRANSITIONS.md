## Chosen strategy

Extend Shell's composition boundary with one deterministic C++ transition controller, not a second framebuffer owner. A bounded cropped snapshot of the previously submitted scene restores the background while a coherent directional field consolidates the actual difference silhouette into the current canonical component. Cache one snapshot and a fixed grain field; do not retain a second full-resolution final scene or run physics. Request at most one outstanding stage; missed stages are skipped. Existing regional UI quality is used first, because its RGB/removal contract is established; fast Pen updates band large areas and can reorder with quality cleanup. No new waveform experimentation is justified by the available evidence. Final/cancel cleanup stays regional and retains old colour classification through existing debt handling.

Full has four intermediate stages, Reduced two, Minimal one, Disabled immediate. These are software budgets, not physically tuned frame rates. Input, pending content work, orientation, scene identity changes, congestion and resource limits settle immediately. Large surfaces beyond the cropped budget appear immediately. Dismissal is optional; navigation never waits for it. First device qualification remains opt-in, disabled by default through Settings > Accessibility; Reduce motion overrides it. Existing panel/AI work begins immediately and input is never gated by decorative state.
